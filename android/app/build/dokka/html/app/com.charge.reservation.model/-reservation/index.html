Reservation

data class Reservation(val id: String = "", val campsiteId: String = "", val lotteryId: String = "", val entrantId: String = "", val createdAt: Instant? = null, val checkInDate: LocalDate? = null, val checkOutDate: LocalDate? = null, val guestCount: Int? = null, val status: ReservationStatus = ReservationStatus.CONFIRMED, val statusChangedAt: Instant? = null, val statusChangeReason: String? = null)

Represents a campsite reservation made using a lottery invitation.

Stores the entrant's stay dates, guest count, reservation status, and cancellation or rejection details.
