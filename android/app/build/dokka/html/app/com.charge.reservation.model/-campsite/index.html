Campsite

data class Campsite(val id: String = "", val ownerId: String = "", val name: String = "", val description: String = "", val promoImageUrls: List<String> = emptyList(), val tags: List<String> = emptyList(), val maxOccupancy: Int? = null, val pricePerNight: Double? = null, val averageRating: Double? = null, val removed: Boolean = false, val rules: String = "", val cancellationPolicy: String = "", val location: String = "", val latitude: Double? = null, val longitude: Double? = null)

Represents a campsite listing, its ownership, and descriptive information.

Availability and individual rating records are stored separately and linked to this campsite through its ID.
